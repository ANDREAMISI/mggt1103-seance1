## Infrastructure Immuable

L'infrastructure immuable est un paradigme où les serveurs ne sont jamais modifiés après leur déploiement. Voici pourquoi c'est crucial en DevOps :

1. **Prévisibilité** : Chaque déploiement est identique
2. **Reproductibilité** : Fini le "ça marche sur ma machine"
3. **Versionnement** : La configuration est dans Git
4. **Rollback instantané** : On redéploie l'ancienne version
5. **Sécurité** : Pas de dérive de configuration
